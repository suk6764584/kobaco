공공광고 업무지원 · 데이터 탐색

공공광고 담당자가 조건을 설정하면 실제 집행 내역, 미디어 이용 현황, 과거 공익광고 효과를 확인하고 같은 원자료를 DuckDB에서 직접 탐색할 수 있습니다.

브라우저 데이터 엔진을 준비하고 있습니다.

📋 조건 기반 광고 집행 의사결정 지원

실제 관측 데이터를 한 화면에서 비교합니다. 매체 단가·ROI·도달수는 임의 생성하지 않습니다.

📌 메뉴 개요

조건 설정 → 타깃의 미디어 이용 → 선택 기관·동일 분류 기관 집행 비교 → 과거 공익광고 인지경로 → 추천 브리프 순으로 확인합니다.

🗂️ 사용 데이터

정부광고 집행내역, MCR 미디어 이용, 성·연령별 OTT 이용, 공익광고 효과조사 등 공개데이터 원자료를 사용합니다.
